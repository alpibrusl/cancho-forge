# The audit's cases (docs/pilot-audit.md section 4). STARTER SET of T2: the groups and the format are final, the table grows with the reference checker (T3).
#
# One case is a block of `key value` lines ended by a blank line. Keys:
#   case <id>                  the id, `<group letter><number>`: v verdict, l limits, r refusals, p protocol, t tls
#   flags <candidate flags>    after `checker serve --port <n> --resolver 127.0.0.1:<n>` (default: none)
#   world <name> <count> <mode> [<arg>]   a world process (pilot/audit/world.cho) serving <count> connections; <name> is w1..w4
#   resolver <queries> <name=answer>...   the stub resolver (pilot/audit/resolver.cho)
#   request <target>           what the driver sends: `/check?url=...`, `/health`...
#   method <name>              default GET
#   timeout <ms>               the driver's deadline for the answer (default 8000)
#   expect <spec>              the checks of pilot/audit/expect.cho
# `@w1`..`@w4` are replaced by the ports of the worlds, `@r` by the resolver's, `@ca` by the test CA's path, in flags, world arguments, requests and specs.
# `--allow-loopback` is the checker's setting that lets it reach 127.0.0.0/8 and nothing else private (docs/pilot-audit.md section 8); the refusal cases run without it.
